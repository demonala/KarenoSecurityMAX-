# Defensive Security Audit Skill

- Never hardcode API tokens, private keys, or credentials in source code.
- Validate and sanitize all external inputs, file paths, and shell arguments.
- Flag command injection, path traversal, insecure deserialization, and SSRF risks during code reviews.
- Enforce least-privilege file permissions and cryptographic best practices (AES-256-GCM, SHA-256).
