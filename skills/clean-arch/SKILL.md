# Clean Architecture & Zero-Slop Skill

- Write modular, single-responsibility functions with explicit error paths.
- Never leave placeholder comments (`// TODO`, `// rest of code here`) when editing files; write complete, working implementations.
- Avoid redundant dependencies when standard library modules accomplish the task cleanly.
- Preserve existing project conventions, indentation, and public interfaces.
